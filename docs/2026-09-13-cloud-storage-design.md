# 网页云端读写衔接

用户已授权继续将网页操作接到现有 PostgreSQL API。

## 行为与范围

登录账户从云端列表及详情恢复数据。游客保留本地模式。新建、编辑、删除、排序、松果管理、文档修改与本地整理结果均经过既有 API 保存。头像作为可选快照字段，允许内置头像和有大小上限的 PNG/JPEG/WebP data URL。

使用一次一个持久化写任务的保守方案：保存期间禁用写操作，保留按账户隔离的本地待保存副本；服务器成功确认后再提示云端已保存。失败可重试，冲突不可自动覆盖远端。创建响应丢失时避免盲重试产生重复仓库。退出前处理未保存状态，旧账户回调不能更新新账户。

本机旧资料由用户明确点击导入，且仅导入空云端账户。导入使用固定幂等键。退出或刷新不清除待保存副本。清除待保存任务前必须保留可恢复的副本。

## 验证

单元测试覆盖真实接口形状、并发写保护、账号退出隔离、失败与恢复、版本冲突、顺序冲突、幂等导入以及引用清理。独立真实数据库 HTTP 测试覆盖验证码会话、CSRF、头像和文档读写、跨连接恢复、版本冲突和删除。浏览器验证登录后的创建、编辑与刷新恢复。

本阶段不接入真实邮件服务或真实 AI worker；开发环境仍为本机测试认证，不能宣称已公开上线。
