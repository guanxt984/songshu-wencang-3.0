# 保持当前分区检查清单

## 输入

- [ ] 模式明确为 `merge`。
- [ ] 当前文档上下文完整且结构有效。
- [ ] 考虑本次允许的追加和新建后，旧前缀可在不删改的前提下形成合法结果：已有章节不超过 20 个要点；空文档可由暂存松果创建首节；旧空引用章节可获得至少一个语义合理的暂存松果 ID。
- [ ] 新增输入仅包含暂存松果。
- [ ] 已记录全部暂存松果 ID，且输入 ID 唯一。

## 内容处理

- [ ] 每颗暂存松果已拆解并判断信息类型。
- [ ] 重复新增材料只合并表达，没有丢失贡献 ID。
- [ ] 来源、限定条件和关键原文得到保留。
- [ ] 冲突、残缺或来源不明的信息被明确标记。
- [ ] 没有加入原始松果之外的新事实或案例。
- [ ] 无合理现有归属的材料进入必要的新分区。

## 不可变检查

- [ ] 文档标题未改变。
- [ ] 所有旧章节的 ID、顺序、标题和摘要未改变。
- [ ] 所有旧要点的文字和顺序未改变。
- [ ] 契约内的人工修改未改变；契约外批注由调用方另行原样保留。
- [ ] 所有旧松果 ID 的数量、归属和顺序未改变。

## 映射检查

- [ ] 每个暂存松果 ID 在输出中恰好出现一次。
- [ ] 没有遗漏、重复或虚构 ID。
- [ ] 每个新增要点都能通过所在章节的 `pineconeIds` 追溯到支持它的暂存松果。
- [ ] 跨主题松果只归属一个主导主题章节，其 ID 没有跨章节重复。

任一项失败时，拒绝整个结果；调用方不得进行部分写回。

如果可保留性预检失败，应在生成前返回明确的契约兼容错误；不要通过删除旧要点、伪造引用或合并旧章节来绕过限制。
