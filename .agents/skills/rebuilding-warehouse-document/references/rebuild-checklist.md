# 全部重新整理检查清单

## 输入

- [ ] 模式明确为 `rebuild`。
- [ ] 输入包含仓库内全部原始松果。
- [ ] 已记录完整输入 ID 集合，且输入 ID 唯一。

## 知识处理

- [ ] 已先通读全部材料，再决定标题和章节。
- [ ] 已区分事实、观点、方法、例子、术语、问题和结论。
- [ ] 章节按语义和阅读路径组织，而非按粘贴顺序或来源分章。
- [ ] 重复材料已合并表达，同时保留全部贡献 ID。
- [ ] 来源链接、作者、时间和关键原文尽量可追溯。
- [ ] 冲突、残缺、来源不明或缺少定义的内容已明确标记。
- [ ] 没有加入原始材料未提供的事实、案例、来源或结论。
- [ ] 正文没有暴露聚类、去重或 ID 处理日志。

## 结构

- [ ] 文档主题明确，不看原始碎片也能理解。
- [ ] 标题层级清楚，每节只讨论一个主题。
- [ ] 没有为了套模板创建无材料支撑的空章节。
- [ ] 每个章节至少有一颗松果支撑。
- [ ] 所有章节 ID 唯一。

## 映射与写回

- [ ] 每个输入松果 ID 在输出中恰好出现一次。
- [ ] 没有遗漏、重复或虚构 ID。
- [ ] 每个知识点都能通过所在章节的 `pineconeIds` 追溯到支持它的松果。
- [ ] 跨主题松果只归属一个主导主题章节，其 ID 没有跨章节重复。
- [ ] 模型只返回候选文档；调用方验证后派生松果架和位置并整体替换，失败时保留原版本。

任一项失败时，拒绝整个结果；调用方不得进行部分写回。
